# Evidência 3: rota sem autenticação que tentaria devolver condições de saúde

## Sem token: a resposta é bloqueada

$ curl -X GET /api/guarda/demo/condicoes
{"codigo":"RESPOSTA_BLOQUEADA","mensagem":"Esta resposta tinha dado pessoal e foi bloqueada para quem não entrou no sistema."}
HTTP 403

## Com token: a rota responde, e o TextoRotulado sai sem o valor

$ curl -X GET /api/guarda/demo/condicoes (com token da ACS)
{"casa":"demo","condicoes":{"rotulos":["Saude"]}}
HTTP 200
