Arquitetura do Corredor Aceso

Documentos de arquitetura gerados dos arquivos Markdown em docs/. Para mudar o texto, edite o Markdown e rode npm run site em docs/arquitetura/diagramas.

  • Arquitetura técnica do Corredor Aceso

    Este documento define as partes da solução, o dono de cada dado e os contratos entre as partes. Ele também mostra onde cada disciplina pontua. A ficha, as seis perguntas e a pergunta de ML continuam em 01-ideia-vencedora.md.

  • Event storming do Corredor Aceso

    Este documento registra as três sessões de event storming do Corredor Aceso. A sessão 1 dá a visão geral e fecha os hotspots. A sessão 2 percorre cada fluxo no nível de processo. A sessão 3 decide os agregados. Os nomes de código seguem o glossário de 03-modelo-de-dominio.md.

  • Modelo de domínio do Corredor Aceso

    Este documento define o modelo de domínio que a equipe constrói até 19/11/2026, 23h55. Ele parte das sessões de 02-event-storming.md e chega aos contextos, aos projetos .NET, aos nomes de código, às regras da situação da casa, aos contratos e aos casos de teste.

  • Modelo de dados do Corredor Aceso

    Este documento define onde cada dado do Corredor Aceso fica gravado, com que forma, por quanto tempo e quem pode ver. Ele cobre o Postgres, o mapeamento do EF Core, as consultas, a retenção, a classificação dos dados, o SQLite do app, as mensagens, os arquivos de ML e a carga da demo.

  • Infraestrutura, CI/CD, releases e repositório do Corredor Aceso

    Este documento fecha onde a VM roda, como ela nasce e é provisionada, como o código vira release, como a release chega à VM e como a equipe opera o que está no ar até a entrega de 19/11/2026 às 23h55. Ele vale junto com arquitetura.md e com o modelo de domínio. A seção 10 lista cada ponto em que este documento muda um dos dois.

  • Guia de diagramas do Corredor Aceso

    Este guia diz qual tipo de diagrama Pele usar em cada vista do projeto, como escrever o .mmd, qual tema aplicar, como renderizar e como gerar o site da arquitetura. Ele vale para todo diagrama em docs/arquitetura/diagramas/.
